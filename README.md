# ОКО Поручни

Настольное приложение для поиска эпизодов, в которых человек движется по
лестнице без контакта кисти с размеченной зоной поручня.

Система использует детектор движения, YOLO Pose и ByteTrack. Для каждого
человека она проверяет центр рамки относительно зоны лестницы, положение
запястий относительно поручней и временной порог. Результат предназначен для
последующей проверки оператором и не устанавливает личность человека.

## Возможности

- отдельная конфигурация для каждой камеры;
- визуальная разметка ROI, лестниц и поручней;
- обработка MP4, AVI, MOV, MKV, WMV и FLV;
- состояния `holding`, `not_holding` и `unknown`;
- сохранение AVI-фрагментов предполагаемых нарушений;
- хранение результатов в SQLite;
- повторная обработка без удвоения результатов;
- безопасная остановка и автоматическое обновление схемы базы.

## Структура

```text
config/             настройки приложения и камер
core/               обработка видео, трекинг и база
gui/                интерфейс PyQt5 и редактор зон
models/             ByteTrack и локальная модель model.pt
tests/              автоматические проверки
utils/              пути, геометрия и визуализация
docs/               инструкции оператора и установщика
scripts/windows/    вспомогательные сценарии Windows
data/videos/        входные видео, не хранятся в Git
data/violations/    выходные фрагменты, не хранятся в Git
logs/               журнал работы, не хранится в Git
```

## Требования

- Python 3.12 x64;
- Windows 10/11 для рабочего интерфейса;
- модель YOLO Pose в `models/model.pt`;
- зависимости из `requirements.txt`.

Модель, видео, база, логи, реальные настройки камер и автономные установщики
исключены из репозитория. Они относятся к конкретному развёртыванию.

## Установка для разработки

```bash
python -m venv .venv
```

Windows:

```bat
.venv\Scripts\activate
python -m pip install -r requirements.txt
```

macOS/Linux:

```bash
source .venv/bin/activate
python -m pip install -r requirements.txt
```

Поместите совместимую модель в `models/model.pt`, затем запустите:

```bash
python main.py
```

При первом запуске `config/cameras.json` пуст. Камеру можно добавить через
интерфейс. Безопасный пример находится в `config/cameras.example.json`.

## Тесты

```bash
python -m pip install -r requirements-test.txt
python -m pytest -q
```

Тесты не требуют рабочей модели или реальных записей с камер.

## Данные и конфиденциальность

Не добавляйте в Git:

- записи с камер и фрагменты нарушений;
- `data/analytics.db` и резервные копии базы;
- `logs/app.log`;
- реальные `config/cameras.json` с координатами и названиями объектов;
- модель компании и автономные установщики.

Перед публикацией проверяйте результат командой `git status`.

## Ограничения

Контакт определяется по попаданию координаты запястья в размеченную полосу
поручня. Модель не распознаёт пальцы и физический захват. После перемещения
камеры, изменения разрешения или ракурса зоны нужно настроить и проверить
заново на контрольных проходах.
