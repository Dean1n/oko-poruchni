# Установка OKO_PORUCHNI на новом компьютере

Инструкция рассчитана на Windows 10/11 64-bit и видеокарту NVIDIA. Все команды выполняются на целевом компьютере.

## 1. Установить программу без интернета

1. Скопировать всю папку `OKO_PORUCHNI` с флешки на диск компьютера, например в `C:\OKO_PORUCHNI`.
2. Открыть скопированную папку.
3. Запустить `УСТАНОВИТЬ_ОФЛАЙН.bat`.
4. Дождаться сообщения `ОФЛАЙН-УСТАНОВКА ЗАВЕРШЕНА УСПЕШНО`.

Скрипт установит системные библиотеки Microsoft Visual C++, сам установит
Python 3.12 x64, если его нет, а затем установит все библиотеки из папки
`Установщики\wheels-win-py312`. Интернет не используется.
Комплект предназначен для Windows 10/11 64-bit. Windows 7 не поддерживается.

Если Python уже установлен и требуется повторить только установку библиотек,
запустить `Установить зависимости.bat`.

## 2. Проверить программу

1. Запустить `Проверить установку.bat`.
2. Должно появиться сообщение `Все основные библиотеки установлены`.
3. Запустить `Запуск.bat`.

При первом запуске база обновится автоматически. Перед обновлением рядом с базой создаётся резервная копия `analytics.db.before_schema_v2.bak`.

## 3. Проверить настройки камеры

В программе открыть нужную камеру и проверить:

- папку с исходными видео;
- папку для записей нарушений;
- отображение зон лестниц и поручней;
- обработку одного короткого контрольного видео.

Рекомендуемый контрольный набор: проход с левой рукой на поручне, с правой рукой, без удержания, со скрытой рукой и проход двух людей одновременно.

Цвет рамки при просмотре:

- зелёный — обнаружен контакт запястья с зоной поручня;
- красный — подтверждённое нарушение после заданного времени;
- оранжевый — видимости рук недостаточно, решение не принимается.

## 4. Если программа не запускается

Открыть командную строку в папке `OKO_PORUCHNI` и выполнить:

```bat
python main.py
```

Текст ошибки также записывается в `logs\app.log`.

Для NVIDIA рекомендуется установить актуальный драйвер видеокарты. Если CUDA недоступна, программа использует процессор и работает заметно медленнее.

## 5. Куда складывать исходные видео

У каждой камеры должна быть отдельная папка внутри:

```text
OKO_PORUCHNI\data\videos
```

Примеры:

```text
OKO_PORUCHNI\data\videos\CBK1.01
OKO_PORUCHNI\data\videos\CBK1.02
OKO_PORUCHNI\data\videos\BK3.5
```

Видео нужно положить в папку той камеры, с которой оно было получено. Не смешивать записи разных камер: координаты лестниц и поручней у каждой камеры свои.

Поддерживаемые форматы: MP4, AVI, MOV, MKV, WMV и FLV.

Желательный формат имени:

```text
CBK1.02 2026-09-21 14-30-00_000.mp4
```

Из такого имени программа определит дату и время начала записи. Если дата не распознана, будет использовано текущее время компьютера.

## 6. Настройка камеры

1. Запустить `Запуск.bat`.
2. В главном окне выбрать нужную камеру.
3. Нажать `Редактировать настройки`.
4. Проверить:
   - ID и расположение камеры;
   - папку с исходными видео;
   - папку для нарушений;
   - путь к `models\model.pt`;
   - порог нарушения в секундах.
5. Для начала использовать порог 1,5–2,0 секунды.
6. Сохранить настройки.

Пути стандартного комплекта могут быть относительными, например `data\videos\CBK1.02`. Это позволяет переносить всю папку программы на другой диск.

## 7. Разметка зон

В окне камеры нажать `Редактировать зоны`. Для настройки выбрать кадр, на котором хорошо видны вся лестница, поручни и путь человека.

Управление мышью:

- левая кнопка — добавить точку;
- правая кнопка — удалить последнюю точку;
- `Ctrl + левая кнопка` — выбрать ближайшую точку;
- `Очистить точки` — начать выбранную зону заново;
- `Сохранить зону` — сохранить текущий многоугольник.

Каждая зона должна содержать минимум три точки.

### ROI — общая зона наблюдения

В режиме `Зона интереса (ROI)` обвести участок, где люди подходят к лестнице, проходят по ней и выходят. Не включать соседние дороги, окна, двери и оборудование, движение которых не относится к лестнице.

### Лестница

В режиме `Лестница` выбрать `Новая лестница`. Обвести не только ступени, но и путь туловища человека. Программа определяет нахождение на лестнице по центру рамки человека, поэтому слишком узкая область только по ступеням работать не будет.

Если в кадре несколько отдельных лестниц или маршей, создать `Лестницу 1`, `Лестницу 2` и так далее.

### Поручень

Сначала сохранить соответствующую лестницу. Затем выбрать режим `Поручень`, номер лестницы и `Новый поручень`.

Поручень обводить полосой вокруг его видимой части, а не линией толщиной в один пиксель. Полоса должна учитывать небольшую погрешность положения запястья, но не должна захватывать большую часть ступеней или обычное положение опущенной руки.

Если у лестницы два поручня, создать два отдельных поручня, привязанных к одному номеру лестницы.

После разметки:

1. сохранить каждую зону;
2. открыть `Управление зонами`;
3. нажать `Проверить все зоны`;
4. нажать `Применить`;
5. нажать `OK`.

Формальная проверка зон проверяет только наличие точек и правильность структуры. Точность обязательно проверяется на контрольном видео.

## 8. Обработка видео

1. Открыть нужную камеру.
2. Выбрать видео в таблице.
3. Нажать кнопку обработки.
4. Для первой проверки выбрать режим с визуализацией.
5. Дождаться сообщения о завершении.

Во время анализа показываются найденные люди, их временные ID, ключевые точки и таймер.

Цвет рамки:

- зелёный — хотя бы одно уверенно найденное запястье находится в зоне поручня;
- красный — обе руки видны вне поручня и превышен временной порог;
- оранжевый — рук недостаточно хорошо видно, решение не принимается;
- голубой — человек находится вне зоны лестницы.

ID — временный номер человека внутри данного видео. Это не ФИО и не распознавание лица. В другом видео тот же сотрудник может получить другой номер.

При нажатии `Остановить` неполный анализ не заменяет завершённые результаты в базе.

## 9. Куда выводятся нарушения

Подтверждённые программой фрагменты сохраняются в папку нарушений соответствующей камеры:

```text
OKO_PORUCHNI\data\violations\ID_камеры
```

Пример файла:

```text
CBK1.02_person_3_2026-09-21_14-30-15_a1b2c3d4.avi
```

В имени указаны камера, временный ID человека, дата и время начала записанного прохода и уникальный номер обработки.

В базе `data\analytics.db` дополнительно сохраняются исходное видео, расчётное время начала нарушения, продолжительность, номер лестницы и имя видеофрагмента.

## 10. Ручная проверка и установление сотрудника

Программа создаёт кандидата на нарушение, но не устанавливает личность и не принимает окончательное решение.

Порядок ручной проверки:

1. открыть сохранённый AVI-фрагмент;
2. убедиться, что человек действительно находится на лестнице;
3. проверить, видны ли руки и был ли реальный контакт с поручнем;
4. сопоставить камеру и время с исходным видео;
5. при необходимости определить сотрудника по внешнему виду, спецодежде, смене, журналу проходной или другим камерам;
6. записать результат: `подтверждено`, `отклонено` или `личность не установлена`.

Рекомендуемый журнал:

```text
Дата и время | Камера | Файл нарушения | ID | Сотрудник | Решение | Комментарий
```

Оранжевое состояние и плохо видимая рука не являются доказанным нарушением.

## 11. Как проверить точность

Для каждой камеры подготовить короткие контрольные ролики:

- удержание левой рукой;
- удержание правой рукой;
- проход без удержания;
- рука рядом, но не касается;
- скрытая рука;
- два человека одновременно;
- вход и выход из зоны лестницы;
- пустая лестница с изменением освещения.

Сначала обрабатывать их с визуализацией. Сравнивать результат программы с заранее записанным фактическим поведением. После ошибки сначала корректировать зоны и только затем временной порог.

Зоны нужно настраивать заново после перемещения камеры, изменения разрешения, масштаба, объектива или геометрии лестницы.

## 12. Где смотреть результаты и ошибки

Результаты и статистика хранятся в:

```text
OKO_PORUCHNI\data\analytics.db
```

Видеофрагменты находятся в:

```text
OKO_PORUCHNI\data\violations
```

Для быстрого открытия использовать `Открыть нарушения.bat`. AVI-файл можно
открыть двойным нажатием в стандартном проигрывателе Windows.

Журнал ошибок находится в:

```text
OKO_PORUCHNI\logs\app.log
```

Для быстрого открытия использовать `Открыть журнал ошибок.bat`. Программа
автоматически дописывает журнал при запуске и обработке. Каждая строка содержит
дату, время, модуль, уровень и сообщение. При ошибке передать разработчику весь
`app.log` или последние строки, содержащие `ERROR` или `CRITICAL`.

## Резервная копия

Перед заменой рабочей версии создать копию всей папки программы с датой в
названии. Не удалять её до проверки новой версии на реальных видео.
